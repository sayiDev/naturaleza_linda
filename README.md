# Naturaleza Linda 

Este proyecto es una página web sobre la naturaleza, realizada como práctica para aplicar lo aprendido en HTML y CSS.

La página busca mostrar la importancia de valorar y cuidar la naturaleza por medio de imágenes, videos y diferente información.

## ¿Qué contiene la página?

- Una imagen y un video sobre la naturaleza.
- Un formulario de contacto.
- Una tabla de una jornada de reforestación.
- Un menú de navegación.
- Un pie de página.

## Tecnologías

Para realizar la página utilicé HTML y CSS.
